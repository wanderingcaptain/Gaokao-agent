```bash
OLLAMA_HOST=127.0.0.1:11434 OLLAMA_NO_CLOUD=1 OLLAMA_NUM_PARALLEL=1 \
OLLAMA_CONTEXT_LENGTH=8192 OLLAMA_MODELS="$PWD/.venv/gaokao-model/models" \
.venv/gaokao-model/runtime/ollama/0.40.16/bin/ollama serve
```

模型服务运行后，可在另一个终端复验：

```bash

```
